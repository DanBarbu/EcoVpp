Price forecast.

This is the user-facing weather → price module. It turns the high-resolution weather nowcast (Open-Meteo refined by the METOC Lagrangian platform) into a 10-minute electricity price curve, so residents and the VPP dispatcher can see when energy will be cheap or expensive. It runs on a browser-side model here; point endpoint at the price-forecast service for live data.

Embed it

Two lines, no framework.

<script src="assets/price-forecast.js"></script>
<price-forecast
   endpoint="/api/v1/price/forecast"
   hours="6" refresh="60">
</price-forecast>

Drop endpoint and it runs the in-browser model (what you see on the left).

Where the numbers come from

Weather: Open-Meteo 15-min NWP (irradiance, wind, temperature), refined to 10-min by the METOC Lagrangian nowcast adapter.

Price: a residual-load merit-order model — PV + wind generation vs temperature/time-of-day demand → €/MWh. Every coefficient is calibratable.

It drives the VPP

The same curve feeds the flexibility-engine: cheap windows relax load limits, expensive windows curtail EV charging and heat pumps — automatically, within 3 seconds.

How to read the chart

Green bars

Cheapest third of the horizon — good time to charge the EV, run the dishwasher, heat the water tank.

Blue bars

Mid-range price. Normal operation.

Amber bars

Most expensive third — the dispatcher curtails shiftable loads here.

Wire it to live data

Run the stack (docker compose up -d), and the price-forecast service serves the real curve at /api/v1/price/forecast. Set METOC_NOWCAST=1 once the METOC Lagrangian code is in place for true 10-minute accuracy.
